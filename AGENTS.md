# Project Instructions & Agent Guidelines

This repository hosts the official Growth Performance Marketing portfolio of **Lê Minh Quân**.

## Integrated Skills & Frameworks
This project has integrated three premier UI design frameworks:
1. **Taste Skill (`.agents/skills/taste-skill/SKILL.md`)**: Anti-slop frontend engineering, brief inference, and anti-cliché enforcement.
2. **Impeccable (`.agents/skills/impeccable/SKILL.md`)**: UI craft, design vocabulary, commands (`/polish`, `/bolder`, `/quieter`, `/audit`), and anti-pattern heuristics.
3. **Hallmark (`.agents/skills/hallmark/SKILL.md`)**: Artisan UI macrostructures, pre-emit self-critique, and 25 slop-test gates.

Always consult [DESIGN.md](./DESIGN.md) before making any visual or structural modifications.

## Core Rules & Commitments
1. **Desktop View is Locked:** Do not modify the desktop layout or desktop styles unless explicitly instructed by the user.
2. **Mobile Layout Integrity:** Preserve the established mobile layout rules:
   * Left-aligned editorial flow for Sections 01, 03, 04, and 05.
   * Centered KPI widgets for Section 02.
   * In Section 05, Role is Line 1, Company is Line 2.
3. **Data Integrity & Confidentiality:** Maintain strict NDA compliance (no confidential restaurant/school names for Fitmar). Only verified metrics are permitted.
